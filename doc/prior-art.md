# Prior art: HPSDR / Hermes / HL2 Protocol 1 emulation on other hardware

Research date: 2026-09-27. Scope: projects that present an openHPSDR Protocol 1 ("old protocol",
UDP port 1024, Metis/Hermes framing) *server* on top of hardware that is not an HPSDR FPGA, plus
local code in `/Volumes/FastDisk/Radio` that could be reused.

Legend: **[V]** verified by reading the repo/source or official docs; **[U]** unverified (from
search snippets, memory, or inference). License "none" = no license file on GitHub, which means
all rights reserved: we can read it for ideas but cannot copy code.

## 3. Key facts about the QMX gathered during the research

Source: QMX operating manual for firmware 1_02_000, https://qrp-labs.com/images/qmx/manuals/operation_1_02_000.pdf. A local text extract was grepped; line numbers are not stable.

- The USB sound card runs at **24-bit, 48 ksps, stereo** [V]. The front end is a QSD sampled by a PCM1804 ADC at 48 ksps, and the internal SDR is a 12 kHz-IF superhet [V].
- **IQ mode** (menu, or CAT `Q91;` / `Q90;`, session only) streams raw ADC I/Q on L/R, "without any demodulation" [V]. This gives **48 kHz of complex bandwidth**. The dial frequency sits **about 12 kHz above the IQ centre**: HDSDR users set LO-to-tune offset = 12000 Hz, and the SDR++ proxy adds 12000 Hz [V, 2 independent sources]. The exact sign for LSB/Q1 settings is [U].
- The manual says that in IQ mode QMX still transmits and receives CW as normal, and "IQ Mode is not suitable for use with WSJT-X and other Digi mode programs" [V]. **Whether Digi or SSB TX from USB audio works while IQ mode is on is [U]** and must be tested. We may have to send `Q90;` before TX and `Q91;` after it.
- **During PTT the IQ stream pauses** [V: SDR++ issue report; details U].
- Digi TX works by measuring the frequency of a single audio tone from zero crossings. By default it takes 100 measurements/s (Minimum samples 480) [V]. The transmitter keys only when the audio amplitude exceeds the **Rise threshold, 80% of full scale** (Fall threshold 60%), so **TX audio must be close to full scale** [V]. The manual says to use SSB (USB) mode for multi-tone and phase modes [V].
- **SSB TX** has been official since firmware 1_02_000 (May 2025). It uses polar modulation (EER) at 12 ksps and can take audio from the USB sound card (CAT `SS0;`) [V]. The CAT `MD` command in the 1_02_000 manual documents only 3 (CW), 6 (FSK/Digi), 7 (CWR), 9 (FSR). **How to select SSB mode over CAT is [U].**
- Other useful CAT commands: `FA` (VFO A), `TQ0/1` or `TX;`/`RX;` (PTT), `Q1` (Digi sideband), `QB`/`QC` (CAT TX-timeout watchdog), `SS` (SSB TX source), `SW` (SWR), `PC` (power out), `SM` (S-meter), `VN` (firmware version) [V].
